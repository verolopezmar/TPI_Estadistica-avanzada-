# Datos

Los datos crudos **no se versionan** (licencia y tamaño). Se regeneran con `data/download_data.py`,
que se agrega en cuanto el equipo apruebe el dataset (Fase 0).

- `raw/`: archivos tal como se descargan de la fuente.
- `processed/`: muestras y tablas limpias generadas por el pipeline (`src/tpi`), en parquet.
